Animated model artwork for the shared reward presentation
========================================================

Five distinct acquired source designs are converted into private runtime GLBs:

Autumn: Harvest Keepsake - POLY STYLE, Treasure_Chest_4a (Batata Studio)
Ocean: Lagoon Pearl - POLY STYLE, Treasure_Chest_1a (Batata Studio)
Space: Moonstone Vault - Stylized 3D Animated Chests, Epic Chest (Bobardo)
Jungle: Meadow Explorer - Low Poly Chest Animated (Ekrem C.)
Candy: Strawberry Bonbon - POLY STYLE, Treasure_Chest_2a (Batata Studio)

Spring Royal, Summer Energy, and Winter Crystal retain their original 2D rigs.
These five replacements also appear as closed chests in round celebrations.

The free source packages were acquired and retained under C:/uworks/TalkQuest.
The adjacent manifest records publisher, version, original product URL, package
hash, source-model and design hashes, texture sizes, and converted GLB hashes.
Acquisition evidence and exact source/export paths are documented in
docs/assets/chest-refresh.md. Marketplace previews are not runtime assets.

All three source packages use the Unity Asset Store Standard EULA. The source
Unity packages remain outside the repository. Licensed GLBs and their import
sidecars are ignored private build inputs and ship only inside the compiled
game pack, not as a reusable asset library. Publisher scripts, controllers,
and demo behaviors are not imported or executed.

The original body designs, UVs, separate lids, and material slots are retained.
Autumn keeps the largest connected lid shell and removes the source skull/bone
clasp and six pointed ornaments. Candy's integral stud tops are lowered into
shallow fittings. Per-design rim anchors exclude decorative handles, wings,
and chains so the opening light follows the actual cavity. The game adds
pastel enamel, warm wood and pearl colors, material response, and a
three-segment edge bevel at 0.28 percent of source width. No procedural grain
is added. Moonstone remaps the original Epic atlas and retains its source
ambient occlusion. POLY's missing review material slots are deliberately mapped
to a theme inset material; this is an adaptation, not original shader fidelity.
Meadow uses the verified blue-prefab geometry export, the same source model as
the green prefab, with an authored green palette. A green source render is not
claimed.

Every runtime Open take is game-authored and continuously sampled: four lids
rotate 92 degrees around their source pivots, while Moonstone's separate cover
lifts 1.16 source units before normalization. POLY supplies static open/closed
parts without chest animation clips. Bobardo supplies Intro, Idle, Open, and
Pickup; Ekrem supplies Open_Close, Rotation, and Shake. Those available source
clips are not the motion shipped by this conversion.

ChestModelView renders the geometry into an adaptive 512-1024 square viewport.
ChestView uses stable 1024-unit design coordinates. Caller-controlled sampling
preserves the existing opening cues, pause, cancellation, and reduced motion.
Viewports stop updating while hidden or paused.

Rebuild all five private models using Blender 5.2, from the repository root:
  blender --background --factory-startup --disable-autoexec --python tools/prepare-chest-models.py --
  python tools/prepare-chest-models.py --optimize
  node tools/package-chest-models.cjs
  npm run import

The converter's --source-root points to C:/uworks/TalkQuest/sources, with the
verified exports in its sibling asset-review/media directory. --output and
--work relocate generated files. The packager accepts C:/uworks/TalkQuest as its
first positional argument. Run the complete five-model conversion before
packaging. Previews and intermediate files stay in ignored build/chest-quality.
tests/godot/chest_models_visual_review.gd supports silent in-game captures with
a graphics renderer and --audio-driver Dummy; it does not touch player saves.
