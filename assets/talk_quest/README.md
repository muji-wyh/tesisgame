# Retired Talk Quest asset records

Talk Quest was removed from the game on 2026-10-06. This directory retains source,
creator, license, acquisition, and animation records for historical reference.
Its manifests describe the retired integration, not the current game inventory.

Tracked runtime artwork was removed with the mode and remains recoverable from
Git history. Private licensed source files may still be present in local
checkouts; they are preserved without being imported or exported. The directory
is disabled with `.gdignore` and an explicit Web export exclusion.

The current game uses Match, Memory, and Voice Pop. Their shared chest models and
audio remain in the active asset directories.
