The transform preserves the strict bag helper's exact bytes and verifies it does not add an `entry = beforeShoppingBagImage(entry)` call. Bag already-reversed and partial-state rejection remain intact. A bag call in the common Foundation chain would reach the bag again through `beforeRetailMedia`; the source deliberately keeps those paths disjoint.

The fifth-ten lexical helper permits only its exact full accepted before/after objects, plus unrelated IDs passing through. Exact before objects are required for existing historical snapshot callers. All other fields or partial changes fail. Source restoration requires the complete exact suffix, unique additions, and absence of those IDs from the prior prefix.

The new source suffix has sixteen rows. The old third-ten negative mutates offset `-(16 + 21)`, and the old fourth-ten negative mutates `-(16 + 1)`, so each still tests its original history boundary. Their original expected values and helper assertions are retained. Fifth-ten tests also mutate each of its sixteen own source records and test duplicate/reordered suffixes.
