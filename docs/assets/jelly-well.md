# Jelly Words playfield artwork

The Jelly Words well uses a quiet cloud pattern in pale blue, cream and mint.
It continues the existing outdoor sky setting inside the play area while keeping
the letter jellies and their word pictures in the foreground. The artwork stays
still, including with reduced motion enabled; it never handles input.

- Creator: Kenney, identified in the original pack license.
- Original source: the user's acquired `Q:/uwok/Kenney Game Assets All-in-1 3.7.0/2D assets/Pattern Pack Extra` library, version 1.1.
- Selected material: `PNG/Default/pattern_005.png`, a 256 by 256 cloud pattern.
- License: CC0 1.0. The original license is retained as
  `assets/images/jelly-match/well/LICENSE-CC0.txt`.
- Acquisition: already acquired locally. No purchase or download was needed.
  The pack preview and actual selected PNG were inspected before integration.
- Integration: the source PNG is copied unchanged to
  `assets/images/jelly-match/well/clouds.png`. The runtime shader recolors its
  original cloud silhouettes and clips the texture to the existing rounded well.
  The gallery preview itself is not shipped.
  Source and integrated SHA-256: `edcb8f76aee9993d50446260bcf17738fbe99ac8f30ea6352b60655547546f4e`.
- Available animation: static raster pattern and vector originals, with no
  animation clips. This integration introduces no animated scenery.

The surrounding panorama and foliage retain their existing
[sky](jelly-sky.md) and [garden](jelly-garden.md) provenance.
