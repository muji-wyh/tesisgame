# Innerscene hospital bed source

The original unbranded **Hospital bed raised backrest** model was acquired from
[Innerscene](https://www.innerscene.com/tools/library/3d-parts/hospital-bed-raised-backrest-6bb95542)
on 2026-10-16. The direct download is
<https://www.innerscene.com/api/library/hospital-bed-raised-backrest-6bb95542/download>.

The original source page states: “Public domain (CC0). Free to use, modify and
redistribute for any purpose, including commercially, with no credit required.”
The [library terms](https://www.innerscene.com/tools/library/terms) state:
“You dedicate the file to the public domain under the Creative Commons CC0 1.0
Universal Public Domain Dedication.” The GLB root metadata also records
`license: CC0-1.0` and `original_design: true`.

`LICENSE-CC0.txt` is the canonical legal code downloaded from
<https://creativecommons.org/publicdomain/zero/1.0/legalcode.txt>. Attribution is
retained for provenance although the dedication does not require credit. No
payment or account was used. Original source/terms HTML snapshots are retained
in the local review workspace, `build/professional-english/clinical-source-review`.

The unchanged GLB is 651,572 bytes, SHA-256
`2d66623eaa1162b358d404df5288ce6a29416fc506b50ffd0718d832435c1ab5`.
It has 62 meshes, 16,488 triangles, six embedded material textures, no external
dependencies, no skins, and no animation clips. Separate mechanical meshes are
not a working rig. `source-inventory.json` contains the complete source inventory.

Codex inspected three actual model views, including 296 × 185 phone renders.
The raised backrest, split rails, blue inset panels and wheeled base remain
recognizable. The model contains no people, injury or depicted procedures.
This is an asset review, not a claim of clinical or human approval. A complete
ward composition needs its own review. Source dimensions are illustrative and
must not be represented as certified equipment specifications.

This directory retains the acquired source for reproducible scene illustration.
It is excluded from the Web export; only reviewed derived images are candidates
for game integration.
