# Card reader source screening

Three original Sketchfab publisher thumbnails were directly inspected in the browser. All remain preview-only: no model was downloaded, converted or integrated and no word-image gate changed. Exact source, creator, CC BY 4.0 metadata and zero-animation reports are retained in receipt.json and the original API responses. visual-observations.json records the separate later visual screening.

The strongest candidate is [Chip and PIN card reader by Mixmamo.studio](https://sketchfab.com/3d-models/chip-and-pin-card-reader-ccc9d1a3f47b4537ac5b8cf75196c40c). Its rounded gray body and colored keys read clearly, but it lacks a card/payment action and carries small branding. The original source page loads in Edge and links CC BY 4.0; its Download 3D Model action requires login. Acquisition and downloaded-model review remain pending. No login was attempted.

The nofurion terminal is dark, elongated and weathered. The oguz1sapmaz preview does not clearly communicate payment. Neither is selected for the current image. These observations are not final gameplay-size review. Existing card-reader pronunciation approval is unchanged.
