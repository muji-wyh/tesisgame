## Native evidence and limits

`render-and-check.gd` uses the actual raw Loader → cache lease → Access → WordArt
→ WordCard path. It injects no fetch callback and substitutes no texture. It
compares original candidate PNG RGBA pixels with loader-decoded RGBA pixels,
requires the exact request generation, and checks two resources and one lease.
It deactivates and trims the cache while the lease is held, proving that the
lease alone retains both images. After all cards are freed it releases the
scope and requires zero resources/bytes/reservations/leases, invalid scoped
URLs and dead texture WeakRefs. Real Retail modules remain draft; module03
must reject all requested modes as `content_pending`.

The established reference sizes are Match 126 by 72 (102 by 52 picture area)
and Memory 144 by 74 (120 by 54 picture area). Both live layouts calculate sizes
from the viewport; these are observed asset-review dimensions, not universal
enforced minima. The harness verifies exact card and picture dimensions,
UI scale 1, no flip/motion scale, and no mouse or keyboard contamination.

Current `game_ui.gd` and `memory_garden.gd` both restore picture opacity to 1.0
after WordCard refresh. Match passes the actual five `MatchConnections` pair
colors, numbered badges and focus states; it also restores the unlocked card's
disabled state. Memory uses the generic badge and unpaired green fill. The
harness copies those presentation settings into real
WordCards. It does not instantiate either complete board. Separate 0.68-alpha
captures are explicitly labeled conservative WordCard stress states; older
asset harnesses' 0.68 matched output must not be represented as current live
Match or Memory output.

Expected output is 15 native bag/basket comparison panels, 30 exact card crops,
a contact sheet, a nearest-neighbor 3x aid and a report. All cue and production
acceptance fields remain false/pending even when every delivery check passes.
No audio is played, changed or regenerated. The original approved Ava descriptor
and recording bytes are frozen. There is no complete module inventory,
production packaging, responsive-board, browser, participant-recognition or
new listening-approval claim.
