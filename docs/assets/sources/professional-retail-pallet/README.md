This is a scratch-only source and candidate review for `pallet.goods-platform.n`. No production asset, content, review status, test or readiness gate is changed. Independent root acceptance is still required.

## Source

The source is [Kenney Mini Skate](https://kenney.nl/assets/mini-skate), created by Kenney under CC0 1.0. The existing local library contains version 1.2; its retained license is dated 2024-02-29. The current source page advertises version 2.0, which is not the version used here. `source-record.json` identifies the exact previously acquired original GLB, external colormap, license and pack preview, all copied byte-for-byte into this scratch folder.

The source contains one static mesh, one node, no skins and no animation clips. No geometry, material, texture or machine/object part was added or edited. The original source preview is distinct from the new native source views and from the eventual term candidate.

## Brief and camera

The unchanged production brief calls for a clean wooden goods pallet in a low three-quarter view, showing top slats, spacer blocks and fork-entry gaps. A carton is optional. The source is clean and empty, so no carton is added. The source preview from the weathered Retro Urban Kit was not pursued for this brief.

Eight native views establish three broad upper slats, chunky lower supports and gaps below the top. The underside is structural evidence only. The selected lower right three-quarter view keeps the upper slats and a side fork opening visible. The near eye-level view reduces the top to thin edges; the near-frontal higher view weakens the three-quarter depth cue; the other side flattens the visible side opening. All original 512 x 512 views remain under `source-inspection/`; its contact is a labeled reduced montage.

Only camera, studio lighting, transparent background, alpha-bounds cropping with a margin and Lanczos resizing are permitted for the candidate. The original file is a stylized compact representation with exaggerated thick slats and no human or workplace scale reference. It is not a dimensionally certified industrial pallet illustration.
