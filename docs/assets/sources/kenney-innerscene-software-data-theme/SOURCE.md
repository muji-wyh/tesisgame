# Digital Studio acquired source and static components

This folder retains exact copies of thirteen Kenney Furniture Kit 2.1 models
under CC0 1.0 and the original Innerscene Mobile Whiteboard under CC0 Universal.
`source-inventory.json` preserves the acquisition record, creator, original
source URL, license, byte count and SHA-256 for each asset. Every copied model
matches that inventory. All fourteen sources contain no animation clips or
skins. Source previews and downloaded HTML are provenance, not runtime artwork.

The sources were imported and composed with their original geometry and
materials. The scene has paired workstations, a review screen and mobile
whiteboard, plus a side analysis desk. The final bounded r04 plant position is
`[-1.42, 0.05, 0.05]`, at scale 1.4 and yaw 0. The native 768-square source scene
retains its fixed camera and lighting. Foreground desks, chairs, laptop and lamp
are isolated with the exact environment/rest difference, including shadows and
correct chair occlusion; compositing the layers reconstructs every source pixel.

`derivation/` contains exact historical renderer and layer-tool snapshots with
`.txt` suffixes so they cannot run during project import. Their original build
paths and precondition labels remain untouched. They are audit evidence, not
instructions to replay a consumed proposal or overwrite earlier render attempts.
`file-destinations.json` maps every retained source and derivation byte stream.

Static placement review uses current Main in Match and Word Jelly at four
viewport sizes. Actual source poses and all 24 Main captures are retained in
`docs/qa/software-data-static-r04/`; 320x568 Word Jelly retains its existing
minimum-window pause overlay. Natural opaque-card occlusion is accepted.
These observations do not establish the other four games, physical devices,
participant recognition, complete module budgets or full-theme acceptance.

The sixteen-frame candidate leaf sway is newly authored local rotation of the
acquired leaf mesh, not an animation supplied by the source creator. It remains
outside production descriptors because normal-speed visual acceptance is still
pending. The accepted Home preview and full-theme readiness are separate.

Only `art.environment` and `art.props` are now integrated: two exact PNGs,
191,271 encoded bytes and 9,437,184 conservative decoded CPU-plus-GPU bytes.
`theme-resource-inventory.json` records these two resources;
`profile-component-change-2026-10-20.json` retains the before/after profile and
proves the other fields remain identical. The scoped acceptance receipt is
`component-review-2026-10-20.json`. The original Home preview, `art.home`,
ambient motion, palette, audio, rewards and 200 ms transition are unchanged.
The full Software & Data profile and all 200 professional modules remain gated.
