# Innerscene electric forklift source

The original unbranded [Electric counterbalance forklift](https://www.innerscene.com/tools/library/3d-parts/electric-counterbalance-forklift-7acc0547)
was acquired from Innerscene on 2026-10-16 through its
[GLB download](https://www.innerscene.com/api/library/electric-counterbalance-forklift-7acc0547/download).
The source page and [library terms](https://www.innerscene.com/tools/library/terms)
explicitly dedicate the original model to CC0, permitting modification and
redistribution, including commercial use. No payment or account was used.

`LICENSE-CC0.txt` retains the canonical CC0 legal code. Source-page HTML and
actual model review captures remain in the ignored local directory
`build/professional-english/logistics-source-review/`. An interrupted first
download is retained there as `first-download.incomplete`; it is not an asset.
The successful GLB passed its declared-length/header check before rendering.

The unchanged source is 706,164 bytes, SHA-256
`e6faa144b0479cd422e8ea6dfc9795468384ae17bd45db58b67c2b2ba657ebaf`.
It contains 81 meshes, 18,460 triangles, five materials, no texture images,
external dependencies, skeletal skins or animation clips. Named mechanical
parts do not establish working articulation. The original materials and
geometry are retained in the derived illustration.

Codex visually inspected actual three-quarter rendering, front/rear phone
views, and the 296 x 185 final warehouse preview. The orange body, overhead
guard, mast and two forks remain distinct. The first room composition was
rejected because oversized source wall modules cropped above the frame; the
accepted composition uses the recorded Kenney wall and floor assets.

This is a static illustrative source review. The model's nominal dimensions
are not certified operating clearance, stability, load rating or safety
instruction. The complete warehouse theme and occupational review remain
pending. This source directory is excluded from Web exports; only separately
reviewed derived images are integrated as Home previews.
