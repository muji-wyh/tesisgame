# Voice Pop acceptance record

Release acceptance for the complete age-based, 200-word game and Voice Pop.
Unchecked items below remain pending and are not release evidence.

## Scope

- Enter Voice Pop through its fourth mode tab; request browser speech permission
  from that action. No recording starts when opening the game.
- Wait for recognition `onstart` before running the 30-second round. Show an
  actionable error for denial, missing speech support, or unavailable microphone.
- While listening, animate the full screen perimeter with multicolor light.
- Throw correctly paired illustrations and English nouns along upward/downward
  arcs, with time to identify and pronounce each target.
- Hit a visible target using recognized speech, remove it immediately, and show
  an impact flash, slash, shards, and shockwave. Repeated hypotheses from the same
  utterance must not hit a later target again.
- Stop at 30 seconds of active play. Pip reports actual hits, words, score and
  best combo, supports a direct interaction, and offers pronunciation review and
  replay.
- Pause on recognition interruption, More, and backgrounding. Release microphone
  and cancel speech on exit. Keep a visible notice if a browser cannot stop it.
- Retain the current age-filtered vocabulary and existing Match/Learn/Memory
  behavior. Fit 320px phones, portrait/landscape, desktop, and reduced motion.
