# Voice Pop acceptance record

Release acceptance for the complete age-based, 200-word game and Voice Pop.
All release checks below are complete. The native speech transcription
limitation is recorded separately from simulated recognition tests.

## Scope

- Enter Voice Pop through its fourth mode tab; request browser speech permission
  from that action. No recording starts when opening the game.
- Wait for recognition `onstart` before running the 30-second round. Show an
  actionable error for denial, missing speech support, or unavailable microphone.
- While listening, animate the full screen perimeter with multicolor light.
- Throw correctly paired illustrations and English nouns along upward/downward
  arcs, with time to identify and pronounce each target.
- Hit a visible target using recognized speech, remove it immediately, and show
  an impact flash, slash, shards, and shockwave. Repeated hypotheses from the same
  utterance must not hit a later target again.
- Stop at 30 seconds of active play. Pip reports actual hits, words, score and
  best combo, supports a direct interaction, and offers pronunciation review and
  replay.
- Pause on recognition interruption, More, and backgrounding. Release microphone
  and cancel speech on exit. Keep a visible notice if a browser cannot stop it.
- Retain the current age-filtered vocabulary and existing Match/Learn/Memory
  behavior. Fit 320px phones, portrait/landscape, desktop, and reduced motion.

## Native browser speech probe

Stable Google Chrome 152.0.7977.83 was also tested with its native recognition
API through the actual Godot Voice Pop tab. A fresh profile used the existing
`word-cat.wav` as fake media input; no physical microphone was captured and no
recognition API was mocked. The trusted canvas gesture retained user activation,
recognition started after about 77ms, audio started after 194ms, and sound/speech
detection events followed. The arena ran and counted down normally. Selecting
Match called native abort; speech/audio/end events followed and the page cleared
its Pop state, disabled the perimeter, and hid the speech panel. No script errors
were observed and the browser/context were closed.

There was **no transcript within the 25-second observation**, so this verifies
native start/stop integration, not successful transcription or physical-device
microphone quality. Full event evidence: `real-pop-probe.json` in the QA folder.

Browser recognition test fixtures never capture the physical microphone. They
exercise SpeechRecognition events through the shipping host and Godot game.
Live speech service availability and recognition quality depend on the user's
supported browser and speech provider; record any real-device verification
separately from simulated recognition tests.
