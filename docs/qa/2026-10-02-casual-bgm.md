# Casual music refresh

Replaced the eight active theme WAVs with eight different Juhani Junkala tracks
from the original CC0 Towns and Calm releases. Source archives and original
license notices were verified; the active source/output hashes and conversions
are recorded in `docs/assets/casual-bgm.json`.

The complete loops retain their durations and tempo. Fixed gain brings every
recording to approximately -20 LUFS, and 3 ms edge fades remove abrupt sample
joins. Measured outputs range from -20.00 to -19.99 LUFS, with true peaks from
-8.84 to -3.60 dBFS. The existing game gain, spoken-prompt ducking, microphone
silence, and theme paths remain unchanged.

## Verification

- All eight recordings pass the existing format/distinctness test, extended to
  pin the reviewed output hashes, headroom, and loop-boundary continuity.
  Log: `build/casual-bgm-assets-tests.log`.
- Five world-audio tests passed, including historical provenance and an isolated
  CLI test that confirms the legacy generator preserves replacements by default.
- The maintained importer recreated all eight exact output hashes from the
  original source Ogg files. Log: `build/casual-bgm-reproduce.log`.
- Output loudness was independently remeasured after conversion and edge fades.
  Results: `build/casual-bgm-loudness.json`.
- Full-length MP3 previews and source/license links are generated by
  `tools/create-bgm-review.cjs` into `build/bgm-review/`. They are separate from
  the game pack and use a user-controlled review volume.
- The Web export passed, including every required packed audio resource. The
  compressed startup bundle is 25.00 MB. Log: `build/casual-bgm-web-build.log`.
- The review page passed Chromium playback checks for all eight preview
  durations and exclusive playback. Its 390 px mobile layout has no horizontal
  overflow, and both desktop and mobile screenshots were visually checked.
  Log: `build/bgm-review-browser.log`; screenshots:
  `build/bgm-review-desktop.png` and `build/bgm-review-mobile.png`.

The initial game browser checks exposed an overly strict duration matcher,
which allowed only one output sample of error. The 90-second Spring source
imports as 1,984,499 frames at 22,050 Hz, and the browser plays 3,968,997 frames
at 44,100 Hz. This is one imported frame plus one output frame of rounding;
actual output is running and nonzero, with no browser errors. The matcher now
accounts for the import rate and output rate, including negative checks for
stopped music. Diagnostic evidence: `build/casual-bgm-playback-diagnostic.json`.

All seven targeted Chromium game checks passed after correcting the matcher:
first-gesture music, suspended-context recovery, visibility and pageshow
recovery, all eight themes while offline, loss-screen stopping, and Voice Pop
quiet mode with immediate music restoration on exit to Match and Memory.
The checks also exercise real destination audio output and bundled playback
without external audio downloads. Log: `build/casual-bgm-browser-verified.log`;
browser artifacts: `build/casual-bgm-browser-verified/`.

The local review is available at `http://127.0.0.1:41776/`. Music selection was
based on the source descriptions and metadata; the checks above verify technical
playback and do not constitute a subjective listening review. This refresh has
not been deployed.
